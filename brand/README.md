# Fabio Media logo

Viewfinder corners around an F whose middle bar is a play button, with the
FABIO MEDIA. wordmark in Inter ExtraBold (letters converted to outlines).
Colours: black #0a0a0c, white #f4f4f6, orange #ff5d3b.

| File | Use it for |
|---|---|
| `logo-white.svg` / `png/logo-white-2000.png` | Full logo on dark backgrounds, video watermarks |
| `logo-black.svg` / `png/logo-black-2000.png` | Full logo on light backgrounds, invoices, documents |
| `mark-white.svg` / `png/mark-white-1000.png` | Icon only on dark backgrounds, small watermark |
| `mark-black.svg` / `png/mark-black-1000.png` | Icon only on light backgrounds |
| `png/profile-picture-1080.png` | Instagram, WhatsApp Business, Skool, LinkedIn |
| `png/google-business-720.png` | Google Business Profile logo |
| `icon-tile.svg`, `png/favicon-192.png`, `png/apple-touch-icon-180.png` | App and home-screen icons |
| `icon-small.svg`, `png/favicon-32.png` | Browser tab (simplified: play-F only) |

The SVGs are generated by `tools/build-logo.py`.
